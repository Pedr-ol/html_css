# HTML e CSS

Repositório destinado aos estudos, exercícios e projetos desenvolvidos durante o aprendizado de **HTML5 e CSS3**. 
Do curso Formação Front-end - HTML, CSS, JavaScript, React e +
Ministrada por: Matheus Battisti


## 📚 Conteúdos

O repositório está organizado em pastas de acordo com os conteúdos e projetos estudados:

| Pasta | Conteúdo |
|---|---|
| `1_Intro` | Introdução ao desenvolvimento web |
| `2_html` | Fundamentos de HTML |
| `3_css` | Fundamentos de CSS |
| `4_TRIBUTO` | Projeto de página de tributo |
| `5_FORM` | Formulários em HTML |
| `6_FORM_PROJECT` | Projeto utilizando formulários |
| `7_RESPONSIVIDADE` | Desenvolvimento de páginas responsivas |
| `8_HDC_HOST` | Projeto de hospedagem |
| `9_FLEXBOX` | Layouts utilizando Flexbox |
| `10_CLONE_HOME_INSTA` | Projeto de clonagem da página inicial do Instagram |
| `11_HTML_SEMANTICO` | HTML semântico |
| `12_BLOG_SEMANTICO` | Projeto de blog utilizando HTML semântico |

## 💻 Tecnologias

- **HTML5**
- **CSS3**

## 🎯 Objetivos

- Aprender os fundamentos do HTML;
- Desenvolver páginas utilizando HTML semântico;
- Aprender estilização com CSS;
- Trabalhar com formulários;
- Desenvolver layouts responsivos;
- Utilizar Flexbox para organização de elementos;
- Desenvolver pequenos projetos práticos;
- Aplicar boas práticas de estruturação de páginas web.
